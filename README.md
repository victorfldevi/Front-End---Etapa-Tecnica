## 📦 Dependências

- **( Bootstrap )** - Conexão com a internet
- **( Navegador )** - É necessário um navegador web atual para abrir a página.

## ▶️ Como Executar

**1.** Utilize o comando `git clone` para baixar o seguinte projeto na sua máquina: `https://github.com/victorfldevi/Front-End---Etapa-Tecnica`

### Ou

**1.** Acesse o link acima, Clique no botão **Code**, depois no botão **Download ZIP**, em seguida extraia a pasta do projeto da pasta compactada.

**2.** Abra a nova pasta que surgiu e clique em **html**.

**3.** Abra o arquivo **index.html** com um navegador atual (Google Chrome, Edge, Opera, etc).

## 📝 Observações

- Caso textos e imagens aparentarem estar fora de escala, verifique se o seu navegador está com zoom diferente de 100%.

- Caso houverem elementos inesperados na página, troque de navegador e/ou verifique sua conexão com a internet.
